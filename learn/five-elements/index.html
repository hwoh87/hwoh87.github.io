목·화·토·금·수는 어떤 관계일까요?

음양오행은 사주 글자들의 성질과 관계를 분류하는 전통적인 틀이에요. 먼저 각 글자의 오행을 찾고, 다음으로 어느 방향으로 생하고 극하는지 읽어보세요.

음양과 오행은 글자를 나누는 두 기준이에요

오행은 목(木)·화(火)·토(土)·금(金)·수(水)의 다섯 분류예요. 음양은 그 안에서 서로 다른 두 측면을 구분해요. 예를 들어 갑목과 을목은 모두 목이지만, 갑은 양목, 을은 음목으로 분류해요.

천간 열 글자를 표에 놓으면 각 오행에 음·양 두 글자씩 배속되는 구조를 볼 수 있어요. 이 분류는 십신을 나누는 기준으로 이어져요.

오행양의 천간음의 천간전통적인 상징

상생: 다음 기운을 생하는 방향이에요

상생(相生)은 한 오행이 다른 오행을 생하는 관계예요. 목 → 화 → 토 → 금 → 수 → 목으로 이어져요. 화살표 방향이 있으므로, 목이 화를 생하는 관계와 화가 목을 생하는 관계는 서로 달라요.

  1. 목 → 화목생화 木生火
  2. 화 → 토화생토 火生土
  3. 토 → 금토생금 土生金
  4. 금 → 수금생수 金生水
  5. 수 → 목수생목 水生木

예를 들어 일간이 갑목이라면 수는 나를 생하는 오행, 화는 내가 생하는 오행이에요. 십신에서는 각각 인성과 식상이라는 묶음으로 읽어요.

상극: 다른 기운을 제어하는 방향이에요

상극(相剋)은 한 오행이 다른 오행을 제어하는 관계예요. 목 → 토 → 수 → 화 → 금 → 목으로 이어져요. 상극이라는 말만으로 불행이나 나쁜 관계가 결정되는 것은 아니에요.

  1. 목 → 토목극토 木剋土
  2. 토 → 수토극수 土剋水
  3. 수 → 화수극화 水剋火
  4. 화 → 금화극금 火剋金
  5. 금 → 목금극목 金剋木

갑목을 기준으로 보면 토는 내가 극하는 오행, 금은 나를 극하는 오행이에요. 십신에서는 각각 재성과 관성으로 묶어요. 같은 관계도 전체 명식에서 어떤 역할을 하는지 함께 살펴야 해요.

오행 개수와 기운의 강약을 구분해요

오행 분포는 여덟 글자가 어느 분류에 속하는지 살펴보는 출발점이에요. 개수만 같다고 작용까지 같지는 않아요. 태어난 계절, 지지 안에 든 천간인 지장간, 다른 글자와의 관계도 함께 보기 때문이에요.

따라서 ‘금이 없으니 무엇을 반드시 해야 한다’거나 ‘목이 많으니 어떤 성격이다’라고 곧바로 결론 내리지 않아요. 같은 오행도 명식 안에서 놓인 자리와 관계에 따라 읽는 맥락이 달라져요.

내 명식의 오행 분포 보기천간 · 지지에서 글자별 배속을 확인해요

처음 볼 때 자주 묻는 질문

상생은 좋고 상극은 나쁜 뜻인가요?

상생은 생하는 관계, 상극은 제어하는 관계의 이름이에요. 단독으로 길흉을 정하지 않고 전체 명식에서의 역할과 강약을 함께 살펴요.

오행이 다섯 가지 모두 있어야 하나요?

오행의 유무와 개수는 기본 정보예요. 모두 있다는 사실만으로 좋은 사주라고 판정하지 않으며, 계절·지장간·글자 사이의 관계도 함께 봐요.

갑목과 을목은 무엇이 다른가요?

두 글자는 모두 목에 속하지만 갑목은 양, 을목은 음으로 분류돼요. 음양 차이는 십신을 구분할 때에도 사용해요.

12운성과 12신살, 무엇을 기준으로 읽을까요?

명식표의 ‘장생’과 ‘역마’는 모두 지지 옆에 보이지만, 서로 다른 기준으로 붙인 이름이에요. 먼저 12운성인지 12신살인지 구분하고, 무엇을 기준으로 계산했는지 확인해 보세요.

12운성은 일간에서, 12신살은 년지에서 출발해요

12운성(十二運星)은 천간의 기운이 각 지지에서 놓이는 상태를 생애의 열두 단계에 빗대어 부르는 체계예요. 삼라만상 명식표에서는 일간을 기준으로 년지·월지·일지·시지 각각의 운성을 표시해요.

12신살(十二神殺)은 기준 지지와 살펴보는 지지의 관계를 열두 이름으로 분류한 체계예요. 삼라만상의 12신살 행은 년지, 곧 태어난 해의 지지를 기준으로 계산해요. ‘일지 기준’으로 설명하는 자료와 비교할 때는 기준부터 맞춰봐야 해요.

삼라만상 명식표에서 십신·12운성·12신살을 붙이는 기준
구분삼라만상 표의 기준살펴보는 글자이름의 예
12운성일간 — 일주의 위 글자각 기둥의 지지장생 · 건록 · 제왕 · 묘
12신살년지 — 년주의 아래 글자각 기둥의 지지지살 · 연살 · 역마 · 화개
십신일간상대 천간 또는 지장간비견 · 식신 · 정관 · 정인

따라서 같은 子(자수)에도 십신·12운성·12신살이 각각 붙을 수 있어요. 세 이름이 서로 다르다고 계산이 모순되는 것은 아니에요. 서로 다른 질문에 대한 분류를 한 표에서 함께 보여주는 거예요.

열두 이름은 순환하는 명칭이에요

12운성은 아래의 순서로 이어져요. 표의 첫 이름을 어디에 놓느냐보다 어느 일간이 어느 지지를 만났는지가 중요해요. 삼라만상은 양간과 음간의 진행 방향을 구분하는 표를 사용해요. 같은 목이라도 갑목과 을목의 운성은 같지 않을 수 있어요.

장생 長生 → 목욕 沐浴 → 관대 冠帶 → 건록 建祿 → 제왕 帝旺 → 쇠 衰 → 병 病 → 사 死 → 묘 墓 → 절 絶 → 태 胎 → 양 養 → 다시 장생.

이 이름은 기운의 상태를 설명하는 전통적 비유예요. 병·사·묘라는 글자를 실제 질병·죽음·수명과 연결하지 않아요. 제왕도 인생의 우열을 정하는 등급은 아니에요.

12신살은 겁살 → 재살 → 천살 → 지살 → 연살 → 월살 → 망신 → 장성 → 반안 → 역마 → 육해 → 화개 순으로 이어져요. 각 신살의 이름과 설명은 용어사전에서 볼 수 있어요.

계산 기준을 비교하는 학습 예시 · 완성된 개인 명식이 아니에요

일간 甲, 년지 子로 기준을 고정해 볼까요?

일간은 甲(갑목), 년지는 子(자수)라고 두고, 살펴볼 지지만 바꿔보는 예시예요. 실제 생년월일시나 나머지 기둥을 제시한 것이 아니므로 한 사람의 풀이로 읽지 않아요.

같은 지지에 서로 다른 기준의 이름이 붙는 예시
살펴볼 지지갑목 일간 기준 12운성자수 년지 기준 12신살
寅 인목건록역마
卯 묘목제왕육해
辰 진토쇠화개
  1. 寅을 볼 때 12운성은 일간 甲과 寅의 조합을 찾아 건록으로 표시해요.
  2. 12신살은 년지 子와 寅의 조합을 찾아 역마로 표시해요.
  3. 일간을 바꾸면 12운성 표를, 년지를 바꾸면 12신살 표를 다시 확인해요. 寅 자체에 언제나 건록·역마가 고정돼 있는 것은 아니에요.

갑목 안내의 12운성 표와 자수 안내의 년지 기준 12신살 표에서 다른 지지도 비교해 볼 수 있어요.

이름이 다르면 기준과 표시 위치부터 확인해요

다른 자료의 ‘운성’이 일간 기준인지, 해당 기둥의 천간 기준인지 확인해요. 신살도 년지·일지 중 무엇을 기준으로 삼았는지 살펴봐요. 삼라만상 명식표의 12신살 행과 별도의 신살 설명은 각각의 계산 기준을 확인하며 읽어야 해요.

예를 들어 12신살의 연살과 별도로 안내하는 도화 관련 항목을 이름만으로 모두 같은 계산이라고 보면 혼동할 수 있어요. 연살 용어 안내에서 기준과 실제 대응 지지를 먼저 확인해 보세요.

건록을 乾祿으로 표기한 자료도 있지만, 이 안내에서는 建祿으로 적어요. 한자 표기 차이와 계산 기준 차이를 구분해 주세요. 이름 하나나 특정 신살의 개수만으로 성격·인기·관계의 결과를 정하지 않아요.

처음 볼 때 자주 묻는 질문

12운성과 12신살은 같은 뜻인가요?

아니요. 삼라만상 명식표에서 12운성은 일간과 각 지지의 관계, 12신살은 년지와 각 지지의 관계를 표시해요. 같은 지지에도 각각 다른 이름이 붙을 수 있어요.

12운성에 병이나 사가 있으면 건강이 나쁘다는 뜻인가요?

병·사·묘는 기운의 상태를 생애에 빗댄 전통 명칭이에요. 이 이름으로 질병, 수명, 실제 사건을 판단하지 않아요.

년지 기준과 일지 기준 신살 중 어느 것을 비교해야 하나요?

우선 자료에 적힌 기준을 확인해요. 삼라만상 명식표의 12신살 행은 년지 기준이므로, 일지 기준으로 만든 표와는 같은 조건으로 비교할 수 없어요.

태어난 시간을 모르면 12운성·12신살도 볼 수 없나요?

확인된 세 기둥의 지지에는 표시할 수 있지만 시지의 운성·신살은 알 수 없어요. 절기나 날짜 경계에서 일간·년지가 달라질 가능성도 시간대 비교로 확인해 보세요.

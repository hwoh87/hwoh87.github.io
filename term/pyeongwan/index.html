십신

편관(偏官)이란

일간을 강하게 제어하는 힘이에요. 결단력과 명예심이 강해 어려운 일을 완수하지만, 본인 스스로를 압박하는 부담이 클 수 있어요.

한 줄로: 극한의 강단·위기 대응·자기 채찍질

강점 키워드

  • 결단
  • 용기
  • 명예

주의 키워드

  • 압박
  • 충돌
  • 과로

한 글자만으로 단정하지 않아요. 편관도 사주 여덟 글자 사이의 관계·강약에 따라 작용이 달라져요.

이 십신의 성질

  • 권력·투쟁·강한 압박을 나타내는 흐름 — 일간을 거칠게 다스리는 칠살
  • 기질: 강제규범·의무·권위·책임감·통제·의협심·투쟁·충성·효도·준법
  • 강점 영역: 외과의·검사·운동선수·기업 임원·CEO — 강도 높은 책임 직군
  • 적당하면 결단력·리더십이 빛나는 강단형 — 위기 대응에 강함
  • 과중하면 형액·법적 갈등·만성 건강 문제·고독 위험
  • 관성이 약하면 결단·책임감 흐름이 부족 — 자녀덕·재물도 약화
  • 인성이 동반되면 살인상생으로 풀려 권위가 학덕으로 전환
  • 양인이 겹치면 강한 의지·돌파력 — 군경·외과 등 전문 직군에 적합

무엇을 상징하나

남자에게
의붓자식·조부·사촌형제
여자에게
외부 권위·조직 관계·시숙

강할 때

  • 관성 강 + 식상 충 부재 → 일찍 자녀 두고 자녀가 똑똑·발달
  • 칠살 강 + 형충 → 가까운 인연(배우자·자녀)과 갈등이 잦음
  • 신강 + 칠살 강 + 형충 → 만성 건강 문제·법적 갈등·재물 어려움 주의
  • 정관 약 + 칠살 강 → 외로움·고독한 추진력

약할 때

  • 관성 약 → 자녀덕 약, 재성 부재 시 재물 부족
  • 신강 + 관성 약 + 재성 동반 → 배우자 덕·장수·가정 안정
  • 신강 + 칠살 약 + 재성 동반 → 관운 좋고 성공
  • 신강에 관성 너무 약 → 그릇이 다듬어지지 않는 흐름
  • 여명 배경 + 신강 → 본인이 가정·관계를 주도하는 흐름
  • 관성 약 + 양인 겹침 → 강한 의지·결단력

여러 개일 때 나타나는 패턴

  • 관성 3개 이상일 때 패턴:
  • 군경·경찰·검찰 등 강도 높은 직군 적성, 의리 강함
  • 형제 인연 약화·건강 주의·부모 유산 약함
  • 사주 전체가 칠살 흐름 → 특수한 운명 — 극단의 무대에서 빛남
  • 신약이면 고독한 추진력·관계 결이 굴곡 있는 흐름, 인성·식신 부재 시 신변·건강 관리가 특히 중요한 구조
  • 신약 + 관성 너무 강 → 그릇 짓눌림 — 인성 보강이 필요
  • 이성·관계 인연이 굴곡 있는 흐름 — 독자적 라이프스타일로 발현되기도 해요
  • 인성 부재 → 이성 인연이 굴곡지고 정서적 보호 장치가 옅어지기 쉬워요
  • 칠살 多 + 신약 → 외부 자극에 노출되기 쉬워 신변 보호가 필요
  • (쉽게 말해: 사방에서 명령이 쏟아지는 격전지의 장수 — 강하면 영웅, 약하면 짓밟힘. 인성(부하 진지)이 생존선.)

직업 친화

외과의·검사·운동선수·기업 임원·CEO

자리별로 달라지는 뜻

같은 십신도 년·월·일·시 어느 기둥에 앉느냐에 따라 작용하는 시기와 영역이 달라져요.

년주 — 조상·초년

조상·뿌리에 권위·압박. 군경·관료 가문 또는 강한 가풍에서 성장. 어릴 때부터 "규율·책임·상명하복"이 몸에 밴 자리 — 의협심·충성심의 뿌리. 천간지지 모두 칠살이면 부모덕 약함.

  • 카리스마
  • 추진력
  • 위기 대응
  • 리더십
  • 의협심·충성심
  • 초년 압박
  • 건강 주의
  • 관재
  • 감정 억압
  • 부모덕 약함

월주 — 부모·사회

사회 청년기에 권력·압박 환경. 외과의·검사·운동선수·기업 임원처럼 "한계 돌파 직업" 적성. 신강+칠살 2~3개 → 부귀 가능. 신약+칠살 3개 이상이거나 1~2개+재성 → 건강·신변 관리에 특히 유의가 필요. 인성 왕이면 문관으로, 칠살 왕이면 무관으로 크게 출세.

  • 승부 근성
  • 전문직 적합
  • 결단력
  • 위기 강함
  • 권력 친화
  • 스트레스 누적
  • 갈등 잦음
  • 건강 적신호
  • 신약 시 건강·신변 관리 유의

일주 — 본인·배우자

일주가 편관 — 배우자가 성격이 강하고 권위적이거나, 본인이 외부 압박을 안고 사는 자리예요. 여명 배경 + 신강이면 본인이 가정·관계를 주도하는 경향, 정관(공적 규범) 약 + 칠살(편관, 강한 압박) 강이면 외로움이 따라요. 관성 약 + 양인(전문 결단)이 겹치면 본인의 의지·결단력이 매우 강한 유형이 돼요.

  • 강한 배우자
  • 공동 도전
  • 위기 결속
  • 카리스마 파트너
  • 부부 충돌
  • 건강 압박
  • 스트레스
  • 관살혼잡 시 재혼 가능

시주 — 자식·말년

자식이 강하고 도전적. 말년에 자식 통한 명예 또는 압박. 후계자가 권력형·전문직 — 자식이 사회적 위치 잡으면 부모도 빛남. 신약+시주 칠살+년월주 식상이면 늦게 자식 두고 성공시킴.

  • 자식 성취
  • 말년 권위
  • 후세 영향
  • 전문직 자녀
  • 자식 갈등
  • 말년 건강
  • 책임 부담
  • 칠살 없음+편인 없음 시 비겁운에 자식 건강 주의

내 사주에서는 어떻게 나올까요?

생년월일만 넣으면 명식·십신·12운성·신살·대운까지 바로 계산해요. 설치도 회원가입도 없어요.
